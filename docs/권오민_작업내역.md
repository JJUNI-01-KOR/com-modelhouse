## 추가·변경 파일

```
Assets/_Project/
├── Data/       ZoneData_Entrance / Living / Kitchen / Room.asset
└── Scripts/
    ├── Core/     IClickable, ZoneData, ZoneVolume, ZoneVolumeBox
    ├── Player/   PlayerController, CursorPicker
    ├── Options/  PartType, OptionItem, OptionPart, OptionApplyTester(테스트용)
    ├── UI/       PanelUI, HUDController, OptionPanelUI, ZoneInfoUI, UIFactory
    ├── Devices/  CoffeeBrewEffect
    └── Editor/   COMSetupTools (상단 메뉴 COM)
Assets/Scenes/MainScene.unity
ProjectSettings/TagManager.asset   ← Interactable 레이어 추가
```

| 스크립트 | 역할 |
|---|---|
| `PlayerController` | FR-01. Input System 전용(`Keyboard.current`/`Mouse.current`), CharacterController, 우클릭 중에만 회전, UI 위 회전 차단, 낙하 시 SpawnPoint 복귀, `ResetPlayer()` |
| `CursorPicker` | FR-03. Interactable 레이어만 5m 레이캐스트, UI 뒤 클릭 차단, MeshCollider면 재질 칸(subMesh)까지 구분 |
| `IClickable` | 클릭 대상 공통 약속(`Highlight`, `OnClick`). 로봇팔이 구현하면 CursorPicker 수정 없음 (NFR-06) |
| `ZoneVolume` / `ZoneVolumeBox` | 구역 하나 = 트리거 박스 여러 개. 박스 사이 이동 시 퇴실·입실 안 찍힘. `Entered`/`Exited` 이벤트 |
| `OptionPart` | FR-29 공통 적용기. 색상형·재질형·모델형(액자·화분) 지원, 커서 강조 |
| `OptionPanelUI` | 파트 탭 + 옵션 목록(색 견본·가격) + 선택 표시 + 합계 갱신 |
| `HUDController` / `PanelUI` | 메뉴 버튼, 패널 하나만 열기, 0.5초 새로고침, 비용 합계 표시 |
| `ZoneInfoUI` | FR-02. 구역 입실 시 3초 표시, 다른 구역 들어가면 교체 |
| `CoffeeBrewEffect` | FR-13 연출. `StartBrew / StopBrew / SetCupFilled` |
| `COMSetupTools` | 상단 메뉴 **COM** 1~6 (구역·플레이어·충돌체·벽지·UI 생성·옵션 목록 갱신) |

## 씬 구성 (MainScene)

```
Zone/  Zone_Entrance, Zone_Living, Zone_Kitchen, Zone_Room  (ZoneVolume + 자식 트리거 박스, Ignore Raycast)
Player (CharacterController, PlayerController) └ Main Camera (CursorPicker)
SpawnPoint (현관)
Option_Wall, Option_Floor (OptionPart)
COM_UI (Canvas: Menu, OptionPanel, LogPanel, ZoneInfoPanel) + EventSystem(InputSystemUIInputModule)
```
- UI 글자는 한글 표시를 위해 TextMeshPro 대신 기본 `Text` 사용

## 김찬중 확인 필요

- `IClickable`: 커피 로봇팔에 구현하면 클릭·강조 자동 (커피 머신·컵은 SRS v2.0상 클릭 대상 아님)
- `OptionItem`, `PartType`: 설계 초안 기준으로 만들어 둠 + `useColor`, `color` 추가 → OptionCatalog에서 사용
- `OptionPart.Clicked`, `ZoneVolume.Entered/Exited`(임시 static 이벤트) → HomeEvents 합류 시 교체
- 재실 판정은 SRS v2.0 "구역 영역" 방식으로 구현됨 → `ZoneLight`(3.05)는 `ZoneVolume.Entered/Exited` 구독
- `CoffeeMachine.Brew()`에서 `CoffeeBrewEffect` 호출
- `ProjectSettings/TagManager.asset`에 `Interactable` 레이어 추가됨 (머지 시 확인)

## 알려진 문제

- `m_floor` 원본 재질 Base Map 색이 파란색으로 바뀌어 있음 → 흰색(`FFFFFF`)으로 되돌릴 것 (에셋 원본이라 저장소에는 안 올라감)
- `m_floor`는 의자·수납함도, `m_walls`는 천장·아일랜드·몰딩도 같이 씀 → 이름으로 대상을 한정해서 해결
- FR-04 "경계에서는 시점 위치 구역만 입실" 아직 미반영 (지금은 캡슐 기준)
